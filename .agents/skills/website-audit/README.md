# Website Audit & Page Reader Skill

Global Antigravity skill for comprehensive website page reading, page-by-page summarization, full-site crawling, UX evaluation, conversion rate analysis, technical QA, and SEO auditing.

## Origin & Primary Source
- **Official GitHub Source:** `https://github.com/appariciojunior/website-audit-skill`
- **Installation Scope:** Global (`%USERPROFILE%\.gemini\config\skills\website-audit`)
- **Compatibility:** Antigravity 2.0 / Agent Skills Specification

## Core Capabilities
1. **Full-Site Systematic Crawler**: Crawls internal navigation, footers, categories, product pages, checkouts, and discovered routes.
2. **Page-by-Page Summarization**: Plain-language 2–5 sentence summaries understandable by business owners.
3. **Deep Structural & Content Extraction**: Sections, headings, body copy, CTAs, forms, buttons, interactive widgets, alt text, and structured data.
4. **UX & Journey Flow Mapping**: Identifies conversion funnels, orphan pages, dead ends, and high-friction drop-offs.
5. **Technical & SEO Audit**: Title tags, meta descriptions, heading hierarchy, canonical tags, schema markup, broken links (404/500), and staging/localhost leaks.
6. **E-commerce & Dashboard Deep Dive**: Evaluates product variants, pricing, reviews, checkout friction, and authenticated admin views.
7. **Prioritized Action Plan**: Formats findings into high-impact action tables (`🔴 CRITICAL`, `🟡 HIGH`, `🔵 MEDIUM`, `🟢 LOW`).

## File Structure
- `SKILL.md`: Main execution instruction and multi-phase audit framework.
- `references/checklist.md`: Itemized checklist across copy, UX, conversion, technical QA, and language markers.
- `references/page-template.md`: Standard extraction schema for per-page audits.
